# عامل چاپ Molido

روی دستگاه صندوق اجرا می‌شود و به Molido اجازه می‌دهد **مستقیم و بی‌صدا**
روی چاپگر حرارتی چاپ کند و کشوی پول را باز کند — بدون گفتگوی چاپ مرورگر.

## چرا این، نه اپ Electron

نصب PWA همین حالا پنجرهٔ اپ دسکتاپ می‌دهد.  آنچه کم بود دسترسی به
سخت‌افزار بود، نه یک پنجرهٔ دیگر.

| | عامل چاپ | Electron |
|---|---|---|
| حجم نصب | ~۲۰ کیلوبایت | ~۱۵۰ مگابایت |
| به‌روزرسانی | وب خودکار به‌روز می‌شود | باید جدا توزیع شود |
| کدپایه | همان وب | یک نسخهٔ دوم که عقب می‌افتد |

## پیش‌نیاز

فقط **Node.js نسخهٔ ۱۸ یا بالاتر**.  هیچ وابستگی دیگری ندارد.

## اجرا

```bash
node agent.js
```

با چاپگر مشخص:

```bash
MOLIDO_PRINTER="POS-80" node agent.js
```

در ویندوز، نام چاپگر همان نامی است که در **دستگاه‌ها و چاپگرها** می‌بینید.
چاپگر باید **به اشتراک گذاشته شده** باشد (کلیک راست ← ویژگی‌ها ← اشتراک).

## اجرای خودکار در ویندوز

یک فایل `molido-print.bat` بسازید:

```bat
@echo off
cd /d "%~dp0"
node agent.js
```

سپس میان‌برش را در پوشهٔ startup بگذارید:

```bash
shell:startup
```

## تنظیمات

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `MOLIDO_AGENT_PORT` | `17777` | پورت محلی |
| `MOLIDO_PRINTER` | چاپگر پیش‌فرض | نام چاپگر |
| `MOLIDO_WEB_ORIGIN` | — | نشانی سرور Molido، با کاما جدا |

اگر Molido روی `http://192.168.100.60:3002` است:

```bash
MOLIDO_WEB_ORIGIN="http://192.168.100.60:3002" node agent.js
```

## امنیت

- فقط روی `127.0.0.1` گوش می‌دهد — **از شبکه در دسترس نیست**
- فقط مبدأهای مجاز می‌توانند درخواست بفرستند، وگرنه هر سایتی که کاربر باز
  کند می‌توانست کاغذ چاپگر را تمام کند یا کشوی پول را باز کند
- سقف یک مگابایت روی حجم درخواست

## بررسی سلامت

```bash
curl http://127.0.0.1:17777/status
```

## اگر عامل نصب نباشد

هیچ‌چیز نمی‌شکند.  Molido خودکار به چاپ معمولی مرورگر برمی‌گردد؛ فقط یک
گفتگوی چاپ اضافه دیده می‌شود.
